# V3 verification and acceptance plan

Mission scope is confirmed. All physical/deployment/performance verification remains open. Numerical targets and measured results are deliberately blank until selected/evidenced. No old V1A percentage, five-session target, poster rating or V2 source check is automatically a passed V3 gate.

Source inspection alone does not establish wiring. | Qualitative contract / controlled review; no numeric limit assigned. |

## Release evidence

A V3 declaration requires reviewed current source/parts/configuration IDs, backward-compatible telemetry, selected real camera/compute, correct frame/model/alert provenance, verified transfer/review, operator failure/recovery behavior and independent representative detection/runtime evidence. All agreed numeric criteria must be recorded and supported before the relevant gate can pass.

Tests must distinguish: no object versus failed model; no sensor versus zero physical reading; replay versus live evidence; viewer disconnected versus all-clear; nominal FPS versus capture time; valid serial frames versus physical sensor samples. Exercise camera/model absence, queue backlog/drops, low storage, stop/restart, transfer corruption and no-actuation behavior.

This planning pass checks record/file coverage, cross-references, baseline preservation, quantity/status inheritance and workbook content/layout. It does not run a V3 detector, train weights, commission hardware, install a service, measure geometry or generate PDFs. New planning checks are separate from later runtime/field validation.
