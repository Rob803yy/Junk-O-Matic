# Archive / historical material, not active V2

Start current work at [the V2 engineering index](../docs/v2/README.md).
This archive preserves older code, examples and stale exports so they no longer
appear to be the working configuration. Nothing here establishes the currently
installed firmware, wiring, dimensions or tested capabilities.

| Area | What is preserved | Why it is separate |
| --- | --- | --- |
| [V1A](v1a/README.md) | Original constant-emitting Arduino stub, permissive Pi logger, old procedures/sample CSVs and former hardware placeholders | Different hardware assumptions and serial/archive contracts; not the current acquisition path |
| [Dataset/model scaffold](dataset-model-scaffold/README.md) | Dashboard, taxonomy/configs, loaders, bootstrap/scanner, placeholder reports and their dependencies/tests | Example data/model metrics, not deployed V2 perception or telemetry |
| [Reference pages](reference-pages/README.md) | Dated former page snapshots | Historical statements retain their original scope; links to original baseline are preserved |
| [R0 PDF exports](exports-r0/README.md) | All 13 old PDFs, unchanged | Stale against current editable sources; PDF generation still held |

[Relocation manifest](relocation-manifest.json) maps all 50 old paths to their
new locations and records source hashes. Dated baseline inventories, source
citations and original test receipts intentionally keep old path names; resolve
them through this manifest. Old Git commits remain available.

No current native CAD, STEP, QET, WireViz, Uno/Pi source, protocol or labeled V2
test fixture was moved. Current editable workbooks and Word corrections remain
under `docs/reconciliation`; their explicitly historical input copies are retained
there because they support the current source reconciliation.

Archived software is opt-in historical work. Its requirements and commands are
local to the archive area, not the repository's default setup. Live/raw data,
local configs and generated inventories remain excluded from Git.
