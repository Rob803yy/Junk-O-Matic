# Enclosure layout entry point

Use the [CAD-R3 enclosure/assembly sources and previews](../v2/mechanical/README.md)
and [dimension provenance](../v2/mechanical/dimensions.json). The orange case's
external orientation is photo-informed; internal installation, Pi model, actual
clearances and measured dimensions remain unverified. The source catalog envelope
is a layout candidate, not an owner measurement or proven ingress rating.

For the next physical record, identify the fitted case/boards, mounting points,
battery removal/access, cable entries/strain relief, fuse/switch access and any
airflow arrangement. Capture the actual layout; do not populate it from a concept
poster or infer a thermal/strength result from a native solid. Wire routing and
power entry remain controlled by the electrical/harness review.
