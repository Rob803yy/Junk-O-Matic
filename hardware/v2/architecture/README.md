# Architecture and digital connectivity / R1

Three architecture .drawio files plus a digital-connectivity .drawio are editable
in diagrams.net. Matching SVG/PNG previews reflect R1. Sources share scene data
in scripts/v2/draft_drawings.py; regeneration replaces manual native edits, so
preserve those edits or change the scene source first. Default regeneration does
not write PDFs. Prior R0 PDFs are stale and held pending owner review.

Green confirms Uno identity; red exposes Pi/sensor conflicts; blue marks
historical observations; orange unknowns; purple proposals. Dashed links are
untraced/proposed. These are evidence markings, not electrical qualification.
S06 reports Pi3B and lost HC-SR04; other sources name Pi4. A02YYUW UART remains
an open alternative, not connected to trigger/echo or implemented in firmware.
Future autonomy/sorting/RTK/intake and performance poster claims are not fitted
capabilities. Version nomenclature is provisional pending owner confirmation.
